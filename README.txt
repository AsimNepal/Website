ASIM NEPAL — PERSONAL WEBSITE

Files:
- index.html
- styles.css
- script.js
- portrait.webp (cropped portrait, head and upper shoulders)

To publish: Upload all four files together to the ROOT of your GitHub repository. Connect that repository to Netlify. No assets folder or build step is required.

The animated 3D mathematical surface uses HTML canvas and JavaScript, with mouse drag to rotate. The site also includes responsive layout, project hover tilt, scroll reveals, and a Gaussian curve visualization. It respects reduced-motion preferences.
